# Any WeCon — Portfolio

Source of [anywecon.dev](https://anywecon.dev): a single-page, bilingual (EN/EL) portfolio built with Next.js (App Router), Tailwind CSS and Motion.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run test:e2e   # Playwright
```

Content lives in `lib/projects.ts`, `lib/oss.ts` and `lib/i18n.ts`; screenshots in `public/shots/<slug>/`.

See [CLAUDE.md](CLAUDE.md) for the stack, structure, content editing, deployment and contribution rules.
